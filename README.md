# Week 2 - Project Module 2: Footprinting with Google Hacking Database (GHDB)

## Overview
In this project, I utilized advanced Google Dorking techniques (GHDB) to discover publicly exposed information and vulnerable systems on the internet. This highlights the importance of OSINT (Open Source Intelligence) in the reconnaissance phase of ethical hacking.

## Tasks Completed

### Task 1: Exposed Security Cameras
Successfully identified 10 live, internet-exposed security camera links that were accessible without authentication. 
* **Dork Used:** `intitle: "webcamXP" inurl:8080`

### Task 2: Open Directory Listings (Math PDFs)
Successfully identified 10 open directory listings containing downloadable mathematics ebooks in PDF format.
* **Dork Used:** `intitle:index.of "parent directory" mathematics pdf`
